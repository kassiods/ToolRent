# Sessões de IA

Uma pasta por integrante. Dentro, um arquivo por sessão relevante.

```
sessoes/
├── kassio/
├── lincoln/
├── victor/
└── nailan/
```

**Nome do arquivo:** `AAAA-MM-DD-assunto.md` — por exemplo, `2026-11-03-implementacao-us05.md`.

---

## Modelo

```markdown
# Sessão — <assunto>

- **Data:** DD/MM/AAAA
- **Integrante:** <nome>
- **Ferramenta:** <qual IA foi usada>
- **Relacionado a:** US / UC / Issue #

## Objetivo

O que você queria resolver.

## O que foi feito

Resumo do que a sessão produziu. Arquivos criados ou alterados.

## Decisões tomadas

Decisões de projeto que saíram daqui. Se alguma virou ADR, aponte qual.

## O que foi rejeitado

Sugestões da IA que você **não** aceitou, e por quê.
Esta seção costuma ser a mais útil da transcrição.

## Verificação

Que comandos você rodou e qual foi o resultado real.
Se não rodou, diga que não rodou.

## Pendências

O que ficou em aberto.
```

---

## Antes de commitar

- [ ] Nenhuma chave, token ou senha no texto
- [ ] Nenhuma string de conexão com credencial
- [ ] Nenhum dado pessoal real
- [ ] A seção "O que foi rejeitado" está preenchida (ou diz explicitamente que nada foi rejeitado)

> Mensagem de erro colada costuma trazer credencial junto. Releia antes de salvar.
